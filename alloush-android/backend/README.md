# Alloush AI backend

هذا الجزء يعمل على الخادم وليس داخل تطبيق Android.

- مفتاح OpenAI يحفظ كـ secret على الخادم فقط.
- التطبيق يرسل الرسالة الحالية وسياق المتصل المحدود.
- الرد من الذكاء الاصطناعي Structured JSON: نوع المحادثة، هل الحالة معروفة، الثقة، الرد المقترح، وهل تحتاج علي.
- الطلب يرسل store=false.
- لم يتم نشر الوظيفة على Supabase بعد؛ النشر وتعيين secrets إجراء على المشروع الحي ويحتاج موافقة علي.
