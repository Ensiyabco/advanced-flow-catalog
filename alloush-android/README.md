# علوش Android V1

نسخة أولية مستقلة عن موقع الأنسياب، موجودة على فرع تطوير منفصل حتى لا تؤثر في الموقع الحالي.

## هدف V1
- علوش يعمل كمساعد شخصي وتجاري لعلي على Android.
- يستقبل إشعارات WhatsApp بعد منح Notification Access.
- لا يرسل رسائل WhatsApp تلقائيًا.
- لا يقرأ قاعدة بيانات WhatsApp الداخلية.
- لا يعدل Supabase أو الموقع.
- يعرض الرسالة الواردة داخل علوش ويجهزها للمراجعة.
- التكامل الذكي مع Supabase ومحرك الرد يضاف في المرحلة التالية.

## الأمان
أي تنفيذ خارجي يحتاج موافقة علي. المحادثات الحساسة يمكن استبعادها من المعالجة.
