# تطبيق إنسياب المتقدم لـ iPhone

مشروع iOS أصلي بـ SwiftUI وWKWebView للموقع الحالي. يفتح روابط واتساب خارج التطبيق ويدعم اختيار صورة عند استخدام لوحة المشرف.

افتح `EnsiyabcoCatalog.xcodeproj` في Xcode 15 أو أحدث، ثم اختر جهاز iPhone أو المحاكي وشغّل المشروع. قبل نشره على App Store يلزم حساب Apple Developer وبصمة توقيع ورقم فريق Apple.
