ربط كتالوج الأنسياب المتقدم بـ Supabase

1) تم إعداد جدول catalog_state مع RLS.
2) ملف supabase-config.js يحتوي Project URL وPublishable Key.
3) لا تضع Database Password أو Secret Key في ملفات الموقع.
4) عند أول عملية حفظ من وضع المشرف، إذا لم توجد جلسة Supabase، سيطلب الموقع بريد وكلمة مرور حساب المدير الموجود في Authentication > Users.
5) بعد تسجيل الدخول تُرفع بيانات الأقسام والمنتجات وإعدادات المتجر إلى Supabase.
6) عند فتح الموقع من جهاز آخر، تُقرأ البيانات المركزية من Supabase وتُنسخ محليًا كاحتياط.
7) localStorage يبقى مؤقتًا كنسخة احتياطية أثناء الانتقال.
